# 青柠校园集市

> 中国大学生校园二手交易平台

## 项目简介

青柠校园集市是一个专为中国大学生设计的校园二手闲置交易平台，融合了闲鱼、转转、小红书和拼多多校园版的风格特点。

## 技术栈

- **前端框架**: Vue 3
- **构建工具**: Vite
- **样式框架**: TailwindCSS 4.x
- **状态管理**: Pinia
- **路由管理**: Vue Router
- **图标库**: Lucide Vue Next
- **图表库**: Chart.js

## 功能特点

### 📱 页面功能
- **首页**: 搜索栏、Banner轮播、校园公告、分类导航、热门推荐、猜你喜欢
- **商品详情页**: 图片轮播、商品介绍、成色说明、卖家资料、收藏点赞
- **发布商品页**: 上传图片、商品标题、分类选择、价格设置
- **聊天消息页**: 类似微信聊天界面、买卖双方聊天、自动回复
- **个人中心页**: 用户头像、校园认证、信誉积分、快捷功能入口
- **校园认证页**: 学号认证、学校选择、认证成功动画
- **后台管理页**: 用户管理、商品审核、数据统计

### ✨ 高级功能
- 点赞动画、收藏动画
- 页面切换动画、骨架屏
- 无限滚动、下拉刷新
- 夜间模式、深色/浅色切换
- AI推荐模块、校园热榜
- 校园跑腿、免费赠送专区、校园论坛

### 🎨 视觉设计
- 中国本土互联网UI风格
- 微信绿色+奶白色+浅灰色+青春橙色点缀
- 卡片式布局、圆角设计、阴影层次
- 渐变背景、高级动画效果
- 移动端优先响应式适配

## 快速开始

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```

## 项目结构

```
src/
├── components/          # 可复用组件
├── views/              # 页面视图
├── stores/             # Pinia状态管理
├── router/             # 路由配置
├── data/               # Mock数据
├── types/              # TypeScript类型定义
├── App.vue             # 根组件
├── main.ts             # 入口文件
└── style.css           # 全局样式
```

## 数据说明

项目包含30+个真实中国校园商品数据，涵盖：
- 考研资料、教材书籍
- 宿舍神器、数码产品
- 游戏设备、自行车
- 美妆护肤、衣服鞋子
- 乐器、体育用品

所有图片均使用SVG内嵌生成，确保稳定性和加载速度。
